راهنمای کاربر (پنجره‌های راهنمای اولین ورود)
=============================================

نصب:
  محتوای این zip را داخل پوشهٔ اصلی پروژه (کنار package.json) استخراج کن و
  وقتی پرسید، فایل‌های موجود را جایگزین (Replace) کن.
  بعد: npx expo start --clear
  (پکیج یا ماژول نیتیو جدیدی اضافه نشده؛ نیازی به build دوباره نیست.)

فایل‌های جدید (پوشهٔ src/features/guide/):
  guideContent.ts   همهٔ متن‌ها (فارسی/انگلیسی)، مرحله‌ها و نگاشت مسیر -> راهنما
  GuideContext.tsx  ذخیرهٔ «دیده‌شده‌ها» روی گوشی، باز/بسته‌شدن راهنما
  GuideHost.tsx     خود پنجرهٔ راهنما (کارت، نورافکن روی نوار پایین، Back اندروید)

فایل‌های تغییرکرده (فقط چند خط):
  src/app/_layout.tsx                          افزودن GuideProvider و GuideHost
  src/features/quran/screens/SettingsScreen.tsx   کارت «راهنمای برنامه» در تنظیمات
  src/features/quran/components/QuranTabBar.tsx   فقط export کردن BAR_HEIGHT و HIDDEN_ROUTES

رفتار:
  - اولین ورود به صفحهٔ «باغ من»: معرفی ۳مرحله‌ای برنامه (با نورافکن روی نوار پایین)
  - بعد از آن، اولین باری که هر صفحه باز شود، راهنمای همان صفحه یک بار نشان داده می‌شود
    (۱۵ صفحه). با ضربهٔ X یا Back اندروید بسته می‌شود و دوباره نمایش داده نمی‌شود.
  - تنظیمات > «راهنمای برنامه»: خاموش/روشن‌کردن راهنمای صفحه‌ها، مرور دوبارهٔ معرفی،
    و «دیدن دوبارهٔ راهنمای همهٔ صفحه‌ها».
  - برای تست سریع: تنظیمات > «مرور معرفی برنامه»، یا پاک‌کردن داده‌های برنامه.

ویرایش متن‌ها / افزودن راهنما برای صفحهٔ جدید:
  فقط guideContent.ts را عوض کن (در متن‌های فارسی «~» یعنی نیم‌فاصله).
