# بسته‌ی به‌روزرسانی Qrn: دانلود صوت، علاقه‌مندی‌ها و باز شدن قرآن از راست (نسخه‌ی ۲)

این بسته روی نسخه‌ی فعلی `main` (کامیت `ececf38`) ساخته شده و ۲۰ فایل را می‌آورد.
تغییرات شاخه‌ی `feature-task` هم داخل آن است، پس لازم نیست آن شاخه را جدا ادغام کنی.

**تغییر نسخه‌ی ۲:** متن و خط‌های صفحه‌ها و طرح جلد که در نسخه‌ی اول وارونه دیده می‌شدند اصلاح شد.
عطف همچنان راست است و جلد از راست باز می‌شود، ولی نوشته‌ها درست خوانده می‌شوند.
این بسته جایگزین زیپ قبلی است؛ اگر قبلی را اعمال کرده‌ای، همین فایل‌ها را دوباره روی آن جایگزین کن.

## روش اعمال (پیشنهادی)

1. در پوشه‌ی پروژه یک شاخه‌ی جدید بساز (مستقیم روی main کار نکن):
   ```powershell
   git checkout main
   git pull origin main
   git checkout -b feature/downloads-favorites-splash
   ```
2. محتوای پوشه‌ی `files` را داخل ریشه‌ی پروژه استخراج کن و اگر پرسید، جایگزین کن (Overwrite).
   یعنی `files\src\...` باید روی `src\...` بنشیند.
3. بررسی کن:
   ```powershell
   git status
   npm run typecheck
   ```
4. اجرا و تست روی گوشی:
   ```powershell
   npx expo start
   ```
5. اگر درست بود:
   ```powershell
   git add -A
   git commit -m "feat: offline audio downloads, favorites, 3D Quran opens from the right"
   git push -u origin feature/downloads-favorites-splash
   ```
   و بعد روی GitHub Pull Request بساز و ادغام کن.

## روش جایگزین
اگر ترجیح می‌دهی بدون کپی دستی: `git apply changes.patch` در ریشه‌ی پروژه (روی main تمیز).

## چه چیزهایی اضافه یا اصلاح شد

**دانلود فایل صوتی**
- دکمه‌ی دانلود کنار هر سوره (کتابخانه، علاقه‌مندی‌ها، دانلودها) با چهار حالت: آماده، در حال دانلود (حلقه‌ی پیشرفت؛ با زدن لغو می‌شود)، دانلودشده (تیک سبز؛ با زدن بعد از تأیید حذف می‌شود)، خطا (علامت قرمز؛ با زدن دوباره تلاش می‌کند).
- صفحه‌ی `/downloads`: حجم کل، فهرست، پخش، حذف تکی و حذف همه با تأیید، دکمه‌ی «دانلود جزء ۳۰» با نوار پیشرفت و توقف.
- سوره‌ی دانلودشده بدون اینترنت پخش می‌شود (از قاری انتخاب‌شده).
- باگ‌هایی که در نسخه‌ی قبلی بودند و رفع شدند: ذخیره‌شدن صفحه‌ی خطای ۴۰۴ به‌جای صوت، ماندن فایل نیمه‌کاره بعد از لغو، نمایش خطا بعد از لغو، شروع دو دانلود هم‌زمان با دو بار زدن، و از دست رفتن فایل‌های وب بعد از رفرش.

**علاقه‌مندی‌ها**
- دکمه‌ی قلب با انیمیشن کوچک، فیلتر «علاقه‌مندی» در کتابخانه، و صفحه‌ی `/favorites` (حفظ، پخش، دانلود، حذف از علاقه‌مندی).
- دو ضربه‌ی سریع پشت‌سر‌هم دیگر لیست را خراب نمی‌کند.

**اتصال به برنامه (چیزی که نبودش باعث کرش می‌شد)**
- `FavoritesProvider` و `DownloadProvider` در `src/app/_layout.tsx` وصل شدند.
- مسیرهای `src/app/downloads.tsx` و `src/app/favorites.tsx` اضافه شدند.
- تب «فهرست» در این دو صفحه فعال می‌ماند.
- همه‌ی متن‌ها از سیستم ترجمه (فارسی و انگلیسی) می‌آیند.

**اسپلش**
- کتاب سه‌بعدی عطف سمت راست دارد و جلد از راست باز می‌شود (کتاب راست‌به‌چپ).
- فقط ساختار کتاب آینه شده؛ بافت جلد و صفحه‌ها (`splashScene.ts`) از قبل برعکس می‌شوند تا بعد از آینه شدن نمای برنامه، متن‌ها درست خوانده شوند.
- لوگوی تختِ پایان اسپلش (`QuranCoverMark`) هم با عطف راست کشیده می‌شود، نه با آینه کردن، پس طرح جلد وارونه نمی‌شود.
- اگر نسخه‌ی قبلی (عطف چپ) را خواستی: در `src/features/quran/config.ts` مقدار `OPEN_FROM_RIGHT` را `false` کن.

## نکته‌ی مهم
تایپ‌چک (`tsc`) بدون خطا گذشت و منطق مدیر دانلود با آزمون خودکار (۱۷ مورد) تست شد.
صحنه‌ی سه‌بعدی اسپلش هم در یک مرورگر بدون نمایشگر رندر و بررسی شد (عنوان صفحه، خطوط و جلد درست خوانده می‌شوند).
اجرای کامل روی گوشی ممکن نبود؛ حتماً یک بار روی دستگاه ببین، مخصوصاً لحظه‌ی تبدیل کتاب سه‌بعدی به لوگوی تخت.
